# Roadmap

## Phase 1: Practical evaluation foundation

- CSV benchmark input
- YAML metric profiles
- Weighted scoring with hard gates
- Text and Markdown reports
- CI and demo validation

## Phase 2: Real-world benchmark adoption

- Domain benchmark packs for finance, legal, operations, and support
- JSONL trace format
- Trend comparison across benchmark runs
- HTML leaderboard export

## Phase 3: Enterprise release governance

- GitHub Pages benchmark reports
- Evaluator plugin interface
- RAG quality and LLM-as-judge integrations
- Release checklist templates
- Integration examples for CI/CD and model governance workflows
